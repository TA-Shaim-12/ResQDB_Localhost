# ResQDB
A database for managing disaster response, relief resources, shelters, and affected people.

ResQDB is a relational database that centralizes disaster-response
coordination for floods and cyclones. Instead of different organizations
(government agencies, NGOs, medical teams) each keeping their own scattered spreadsheets during an emergency, everyone reads and writes to one shared database that tracks: who's affected, where the shelters are and how full they are, what supplies exist and where, who's requesting help, and who has already received relief.
